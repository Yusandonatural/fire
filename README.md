# FIREへの道

お金の不安をなくすための家計シミュレーター。
収入・支出・家族構成から、9種類のFIREへの到達度と「お金の心配のない状態」までの距離を計算します。

- 児童手当・公的年金・新NISA・教育費を家族の年齢から自動で織り込みます
- 計算はすべてブラウザの中で行われ、入力したデータは外部に送信されません
- 家計診断をPDFで書き出せます

## 構成

`index.html` 一枚で完結しています。ビルド工程はありません。
GitHub Pages で公開し、`index.html` を差し替えて push すれば更新されます。

外部から読み込んでいるのは Google Fonts と cdnjs（PDF書き出し用）のみです。
